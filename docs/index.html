1.4.4 语音分析

🌐 在线教程 / 使用手册

  • 🌐 wrassp 入门教程 — 介绍如何使用 wrassp 包进行音频信号分析，含实例与语法讲解。是 R 对 Michel Scheffers 的 libassp（高级语音信号处理器）库的封装。支持处理常见音频格式并执行语音科学常用的分析功能，包括：共振峰、基频、均方根能量、自动相关、频谱分析、零交叉率、滤波等。该包为 R 提供了 libassp 功能的主要子集，力求以用户友好的方式服务于语音信号分析。⭐⭐⭐⭐⭐

  • 🌐 soundgen 教程：声学分析 — 基于 seewave 的功能，扩展了音频合成、处理和分析的高级函数。适用于声学特征提取与声音合成任务，特别适合语音/动物声音分析教学与研究。⭐⭐⭐⭐

  • 🌐 EMU-SDMS 官方手册 — EMU 语音数据库管理系统（EMU-SDMS）为一个集成式语音数据库解决方案，支持语音数据的生成、注释、查询、分析与管理。系统介绍 EMU 的结构、标注、音频管理与可视化工具，适合深入研究语音数据库的用户。⭐⭐⭐⭐⭐

  • 🌐 国际音标在线输入键盘 — 可交互地输入国际音标符号，适合语音学学习、作业编辑与标注使用。⭐⭐⭐⭐

  • 🌐 Praat 脚本资源（UCLA） — 提供常用的 Praat 脚本集合，用于自动化语音信号分析任务。⭐⭐⭐⭐⭐

  • 🌐 语音学基础练习：The Articulatory System — 开源教材中的一章，介绍发音器官及基本发音方式，适合初学者练习。⭐⭐⭐⭐

  • 🌐 R 语言绘制元音图教程 — 教你如何使用 R 可视化元音的 F1-F2 图，适用于语音学与音系学研究。⭐⭐⭐⭐

  • 🌐 用 R 绘制 Praat 风格图形 — 教程介绍如何使用 praatpicture 包生成波形图与频谱图，风格接近 Praat。⭐⭐⭐⭐

  • 🌐 EMU-R 系统概览章节 — 介绍 EMU-SDMS 系统的整体结构、主要模块和工作流程，是进行语音数据库管理的关键参考。⭐⭐⭐⭐⭐

  • 🌐 SWPhonetics：基于共振峰计算元音发音位置 — 提供详细算法与可视化方法，支持在线计算与下载数据。⭐⭐⭐⭐

  • 🌐 社科院语音数据库 AESOP — 包含多语言语音语料，适用于跨语言声学分析、语音合成与识别研究。⭐⭐⭐⭐⭐

1.4.5 统计建模

📘 图书资源

  • 📘 Learning Statistics with R: A Tutorial for Psychology Students and Other Beginners — 面向心理学初学者的统计入门教材，内容涵盖描述性统计、推论统计及线性建模，风格友好。⭐⭐⭐⭐⭐

  • 📘 Hands-On Machine Learning with R — 以实际应用为导向，系统介绍机器学习在 R 中的实现，包括支持向量机、随机森林等。⭐⭐⭐⭐

  • 📘 Statistical Thinking for the 21st Century — 现代统计思维教材，强调模型建构与理解而非公式推导，适合数据科学初学者。⭐⭐⭐⭐
